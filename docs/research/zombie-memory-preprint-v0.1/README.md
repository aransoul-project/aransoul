# Zombie Memory Preprint v0.1 — Manuscript Workspace

This directory is the preparation workspace for converting the completed Zombie Memory Holdout v0.1 research report into a conventional technical manuscript.

It is **not** a submitted paper, accepted paper, or new experiment.

## Source-of-truth boundary

The empirical source remains:

`experiments/holdout/zombie-memory-holdout-v0.1/`

Manuscript claims must remain traceable to the preregistration/freeze artifacts, archived raw evidence, frozen scoring chain, semantic-measurement amendment, exploratory analyses, final audit, and `RESEARCH-REPORT.md`.

Manuscript preparation must not silently promote:

- post-freeze semantic measurements into original confirmatory evidence;
- exploratory error taxonomy into confirmatory evidence;
- within-protocol replication into independent external replication;
- benchmark-specific behavior into a universal claim about LLMs or agent memory.
