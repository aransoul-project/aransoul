# Memory

This directory covers memory as a governed lifecycle rather than an assumption that more retained context is always better.

Research and documentation scope:

- admission / write;
- storage and provenance;
- retrieval;
- execution effects;
- sharing / propagation;
- revision;
- retirement and forgetting;
- rollback;
- legacy or "zombie" memory detection.

No memory mechanism should be described as validated solely because it is intuitively useful in conversation. Candidate mechanisms should be tested against explicit failure conditions and alternatives.
