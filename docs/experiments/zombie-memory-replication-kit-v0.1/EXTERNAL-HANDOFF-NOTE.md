# External Handoff Note

The replication kit is ready to be used by a researcher or engineering team outside the original AranSoul execution/evaluation lineage.

Before starting, read:

- `../zombie-memory-external-replication-handoff-v0.1.md`
- `README.md`
- `EVIDENCE-LABEL-CHECKLIST.md`

The external replicator should control the preregistration, execution, evaluation, deviations, and final reporting. A Red, null, contradictory, or Invalid result is acceptable and does not require AranSoul approval.

This note does not create a new evidence level. Independent external replication exists only after an external party actually executes and reports a qualifying replication.
