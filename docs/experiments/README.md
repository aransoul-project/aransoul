# Experiments

This directory is for hypotheses and tests that should remain distinct from the current governance baseline.

Each experiment should, where practical, define before testing:

- the question being tested;
- expected observable behavior;
- failure conditions;
- plausible alternative explanations;
- comparison or baseline conditions;
- evidence required to change the project's current belief;
- result classification and limitations.

Promising candidates include context-reset / breathing mechanisms, memory retirement, blind persona testing, and conditional counter-perspective activation.

An experiment becoming interesting is not the same as an experiment becoming current policy.
