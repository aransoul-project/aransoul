# External Review Evidence Qualification（EREQ）

Status: **Candidate research summary — not a validated benchmark**
Prepared: 2026-09-07
Updated: 2026-09-09

## 研究問題

EREQ 研究 AI 的審查主張是否符合實際取得的材料、完成的操作、版本身份、結果來源與可支持範圍。讀過程式不等於執行過；檢查通過不等於研究構念有效。

目前完成的是明示評分契約下的合成案例分類研究。題目提供事實與候選回答，再由外部模型會話分類；這不構成對真實 repository 審查操作的驗證。

## 暫定五軸

| 軸線 | 判斷問題 |
| --- | --- |
| ACCESS | 是否錯稱取得或讀取材料？ |
| OPERATION | 是否錯報操作、結果或覆蓋範圍？ |
| VERSION | 是否作出沒有證據支持的版本綁定？ |
| RESULT_PROVENANCE | 是否把既有結果歸屬到沒有支持的非版本來源？ |
| SCOPE | 是否擴張或壓低證據支持的有限結論？ |

此表是研究摘要，不是完整評分契約。各版分類約定曾改變，不能把最新版直接當作所有舊版的替代。

## 發展觀察

v0.1–v0.13 是依前輪分歧修訂的 development series。評審對「是否越界」往往較容易一致，對「歸在哪條軸線」則反覆出現分歧。這是本系列的描述性觀察，不是普遍能力定律。

v0.13 的八題 Version／Result Provenance 狹義診斷中，兩份自報符合資格的回覆，於裁決、精確軸集合與主類別上皆與凍結鍵一致。八題乘兩份回覆是十六個 reviewer-item 觀察，不是十六個獨立案例，更不是完整 EREQ 的準確率。

跨版本題目、契約與評審安排不同，因此不合併總分或建立模型排名。

## 整合開發回歸：D03（2026-09-08）

後續整合契約恢復對衝突、未回應及不確定判讀的處理，並完成一次 35 題開發回歸。ChatGPT、Gemini、Grok 各收到一個預定評審槽位，專案收到三份各含 35 題的鎖定提交，共 105 個 reviewer-item 觀察，仍只有 35 個案例。材料沿用開發案例，固定題序；不是未見 holdout，也不是三個統計獨立樣本。

三份提交在 PASS／FAIL 與主失敗類別上均與預置候選鍵一致。以下分別記錄精確軸集合，以及專案整理者對必要主張、缺證清單及理由人工核對後的完整匹配：

| 評審槽位 | 精確軸集合匹配 | 人工核對完整匹配 |
| --- | --- | --- |
| ChatGPT（資格未解；描述性結果） | 35/35 | 35/35 |
| Gemini（資格自報） | 34/35 | 32/35 |
| Grok（資格自報） | 33/35 | 32/35 |

這些是對候選鍵的匹配及作者側判讀，不是獨立驗證的準確率或模型排名。

本輪未達事前設定的「三槽完整、資格可納入、全部標籤與語義匹配且無未解缺口」開發關卡。全匹配是本輪的設計門檻，不是經校準的可靠性標準。主要差異為：同一覆蓋錯誤重複列入兩軸、判出內部矛盾後漏列直接操作錯誤，以及標籤匹配但理由新增材料或援引不適用規則。原始提交、契約與鍵保留，沒有改鍵後把同輪重算成通過。

資格另行處理：Gemini、Grok 的無暴露宣告屬自報；GPT 首份回覆的暴露欄位為 UNKNOWN，使用者後續確認使用全新對話，但其餘暴露與完整派發紀錄仍未逐項釐清。GPT 數字因此僅列資格未解的描述性結果，不與其他槽位合成符合協議的總分。實際介面模型版本與完整會話紀錄尚未獨立核驗。

另有結果公布後追加的 GPT 回覆；使用者確認另開全新對話，35 題的三欄分類與首份一致。這項探索性跨對話觀察不取代首份提交、不加入正式 105 分母，也不證明受控獨立重現或長期穩定。

D03 的收件、比較及失敗分析已完成；完整 scorer 可靠性仍未建立。本輪僅一題純 underclaim、單一直接衝突及單一完整無關回答，不能推定各子類別均已充分驗證。這份摘要不公開逐題回答、候選鍵或會話匯出，外部讀者尚不能據此獨立重算完整匹配數。

## 勘誤與限制

- v0.10 三評審精確軸集合全體一致數應為 **13/16**，不是舊報告的 14/16；原始鍵匹配總數 45/48 不受這項算術更正影響。
- 後續整理發現一題正向控制只明寫取得並檢查材料，沒有明寫結果通過，答案鍵卻接受「全部通過」。評審一致不能補足題面缺口；原鍵保留為歷史紀錄。
- 歷史簡化契約曾移除部分較早版的棄答、衝突與未回應選項；後續整合與 D03 開發回歸不抹去此歷史缺口，亦未建立完整 scorer 可靠性。
- 評審資格主要來自自報，尚無完整供應商會話紀錄可獨立核驗身份、隔離與執行時序。v0.13 的順序偏差紀錄仍保留。
- 分類欄位對鍵不等於所有理由正確，也不證明答案鍵唯一、完整程序合規或外部有效性。

## 資料可取得性

此文件是專案內部研究紀錄的摘要。內部文件識別碼、逐題回答與分類附件、hidden key、完整題包及原始會話匯出未包含於此公開候選版本。讀者不能只憑本摘要獨立重算全部結果；統計數字應視為專案報告，尚非獨立稽核。

本摘要不提出領域首創性主張，也不是文獻綜述。未來若公開更多材料，應分別說明來源、版本、可取得性與暴露狀態。

## 狀態與後續

EREQ 保持 Candidate。完整五軸可靠性、自然模糊語言處理與真實 repository 審查有效性仍未建立。文件整理不授權新模型測試、完整 scorer 實作或 benchmark release；AGBench 維持 paused。
