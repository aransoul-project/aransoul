# Metacognition

AranSoul's current metacognitive sequence is organized around five questions:

1. **問其所見** — What is actually observed?
2. **辨其所假** — What is being assumed?
3. **觀其未見** — What relevant information is missing or unseen?
4. **衡其所變** — What changed, and is the update driven by evidence or belief?
5. **驗其所成** — Did the resulting conclusion or action withstand verification?

The purpose is not to force visible chain-of-thought or produce a post-hoc explanation for every answer. The purpose is to improve governance around evidence, uncertainty, belief revision, and verification.

This directory will later separate operational checks, evaluation methods, and historical versions.
