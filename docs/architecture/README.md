# Architecture / Perspectives

This directory documents how AranSoul organizes multiple perspectives without treating every named role as an independent agent, authority source, or always-on component.

- [Zero and activation](zero-and-activation.md) — focused notes on Zero / 破曜 and conditional counter-perspective activation.

## Current architectural rule

A named perspective may provide a reasoning lens without gaining execution authority.

In particular:

- identity ≠ function;
- function ≠ authority;
- participation ≠ speaking order;
- speaking order ≠ decision priority;
- a named perspective ≠ proof of an independently implemented agent.

## Activation rule

AranSoul currently favors **selective activation** over automatic full expansion. Additional perspectives should be activated when they materially add a new evidence path, risk, alternative explanation, or synthesis—not merely to restate the same conclusion in multiple voices.

Some scheduling ideas, resonance formulas, language-fingerprint mechanisms, and automatic persona ranking remain conceptual or candidate designs rather than established implementations.
