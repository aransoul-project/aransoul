# Governance

This directory documents AranSoul's current governance mechanisms and authority boundaries.

## Current documents

- [Core flow](core-flow.md) — entry positioning, governance thresholding, work states, work cycle, monitoring, metacognition, transition, verification, and evidence commitment.
- [Authority model](authority-model.md) — governance roles, HALT boundaries, ElderCouncil, consultation, and final authority.
- [Human authority](human-authority.md) — separates epistemic sufficiency, governance validity, and execution authority.
- [External action verification](external-action-verification.md) — verifies whether tool-mediated work was generated, sent, reached, persisted, and correctly placed.
- [Refinements](refinements/) — dated changes that modify how an earlier formal baseline should be interpreted without erasing its provenance.

## Current interpretation

AranSoul's governance is not a claim that every named concept corresponds to an independent software module or autonomous agent.

In particular, the evidence-commitment responsibility historically named **格譜定言** is retained as a governance function, while its independent-module status has been refined into `度其治` / output-boundary governance.

## Preservation rule

Historical terminology must not be silently promoted into current policy. Likewise, later refinements should not rewrite earlier formal records as though the earlier state never existed.
