This directory documents AranSoul's current governance mechanisms and authority boundaries.

- [Core flow](core-flow.md) — canonical process map for entry positioning, governance thresholding, work states, work cycle, monitoring, metacognition, transition, verification, and evidence commitment.
- [Authority model](authority-model.md) — canonical authority map for final human authority, ElderCouncil, Six-Soul deliberation, HALT boundaries, execution roles, and major-governance precedence.

## Operational companions

- [Human authority](human-authority.md) — explains the operational distinction between epistemic sufficiency, governance validity, and execution authority.
- [External action verification](external-action-verification.md) — explains how tool-mediated work is verified across generated, sent, reached, persisted, and correctly placed states.

Operational companions clarify or apply the canonical documents. They do not independently redefine formal authority or governance precedence.

## Refinements

- [Refinements](refinements/) — dated changes that modify how an earlier formal baseline should be interpreted without erasing its provenance.
- [2026-08-11 evidence commitment refinement](refinements/2026-08-11-evidence-commitment.md) — retains the evidence-commitment function historically named 格譜定言 while removing the requirement that it remain an independent runtime module.

A current refinement may change the present interpretation of an earlier canonical description. It does not rewrite the historical record as though the earlier state never existed.

## Reading precedence

When governance documents appear to overlap, use this order:

1. explicit later formal human ruling;
2. applicable dated current refinement;
3. canonical authority/process documents;
4. operational companions;
5. historical or superseded descriptions.

This reading order applies within the GitHub documentation layer. It does not replace the broader AranSoul governance precedence recorded in the authority model.

## Current interpretation

AranSoul's governance is not a claim that every named concept corresponds to an independent software module or autonomous agent.

In particular, the evidence-commitment responsibility historically named **格譜定言** is retained as a governance function, while its independent-module status has been refined into `度其治` / output-boundary governance.

## Preservation rule

Historical terminology must not be silently promoted into current policy. Likewise, later refinements should not rewrite earlier formal records as though the earlier state never existed.
