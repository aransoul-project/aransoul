# Governance

This directory will document AranSoul's current governance mechanisms.

Initial scope:

- problem-entry classification and routing;
- governance-depth determination;
- evidence sufficiency and conclusion withholding;
- work-cycle verification and fallback;
- conditional multi-perspective activation;
- human final authority;
- change control for moving concepts between current, candidate, historical, and retired states.

Detailed specifications should be added only after reconciliation with the current source archive. Historical terminology must not be silently promoted into current policy.
