# Zombie Memory Project

Zombie Memory is an AranSoul-originated research project about a specific governance failure mode: information may remain remembered, relevant, or historically correct without retaining present decision authority.

This page is a **project-level navigation map**. It does not relocate, duplicate, or supersede the underlying artifacts.

## Project boundary

Zombie Memory has its own research question, executable benchmark artifacts, empirical evidence chain, replication materials, publication record, and citation identity. It is therefore treated as an independent research project **hosted inside the AranSoul monorepo**.

This page does not authorize moving the project to another repository. Existing paths remain canonical until a separate migration decision is explicitly made.
