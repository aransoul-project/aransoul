# AGBench Research

AGBench is an incubated research project inside the AranSoul monorepo. It studies observable governance and adjudication boundaries in AI evaluation.

## Current public-safe materials

- [`pilot-v0.1/`](pilot-v0.1/README.md) — static measurement-design snapshot. Status remains `development_only` and `PAUSED_AFTER_STATIC_MEASUREMENT_DESIGN_CLOSURE`.
- [`underspecification-gate-v0.1.md`](underspecification-gate-v0.1.md) — exploratory governance note on identifying decision-rule underspecification before single-gold scoring.

## Important boundary

The exploratory Underspecification Gate work does **not** reopen, modify, or supersede the Pilot v0.1 static closure. It is a separate research note intended to inform future benchmark design and adjudication.

No material in this directory should be treated as a released benchmark, model leaderboard, preregistration, or authorization for live evaluation unless a future artifact explicitly changes that status.
