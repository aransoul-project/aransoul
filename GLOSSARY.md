# AranSoul Glossary

This glossary provides a bridge between AranSoul's native poetic terminology and externally readable functional descriptions. A poetic name does not by itself establish a technical mechanism.

| AranSoul term | Functional description | Status note |
|---|---|---|
| 嵐魂 / AranSoul | Long-running human–AI collaboration framework | Current project identity |
| 嵐印語 / SAIIP | Historical structured/poetic language lineage within AranSoul | Historical lineage; specific mechanisms require separate evidence |
| 格譜判位 | Problem-entry classification / governance routing | Current governance concept |
| 度其治 | Governance-depth, risk, evidence, permission, and output-commitment thresholding | Current governance concept |

| 破曜 / Zero | Counter-perspective / adversarial check used under conditions | Conditional governance role; not final authority |
| 殭屍記憶 | Legacy memory or structure that persists after losing current authority or usefulness | Current memory-governance concept |
| 微光輕叩 | Low-force, context-sensitive recommendation / weak-signal intervention | Current governance concept; does not independently halt or authorize action |
| 皆為我覺醒的語 | Project motto; historically associated with broad persona invocation | Motto, not a mandatory execution command |

## Translation rule

Public documentation should use two layers where helpful:

1. **Native term** — preserves AranSoul's historical and poetic identity.
2. **Functional description** — states what the concept is intended to do in language that can be compared with other systems.

Neither layer should be used to imply empirical validation that has not occurred.
